# 04 - ביצוע מיפוי ודיווח שותף

## מטרת התהליך

לאפשר לשותף המיפוי או לצוות השטח לדווח בצורה אחידה אם המפה הושלמה, בוטלה או לא הושלמה, בלי לאבד מידע בדרך.

## מה ידוע לנו

- הביצוע מגיע אחרי ש-OPS בנה משמרת מתוך מפות מוכנות וזמינות עובדים.
- כיום שותפי מיפוי עובדים בקבצים נפרדים.
- יש צורך בטופס או פורטל דיווח יומי.
- מפות שבוטלו או לא הושלמו עלולות להישכח אם הן לא מתועדות ידנית.

## הבעיה

דיווחי ביצוע מגיעים בצורה לא אחידה. חלק מהמידע יכול להישאר בקובץ צדדי, בצ'אט, בסיכום יומי או אצל שותף המיפוי. OPS צריך לאסוף את הסטטוס האמיתי מכמה מקורות.

## איך פותרים את זה היום

| שלב היום | פעולה |
|---:|---:|
| קבלת משמרת | שותף המיפוי מקבל מפות לביצוע |
| ביצוע | המיפוי מתבצע בשטח או אצל השותף |
| דיווח | הדיווח מגיע בקובץ, הודעה או סיכום |
| עדכון OPS | OPS מעדכן ידנית את המעקב המרכזי |
| חריגה | ביטול או אי-השלמה דורשים טיפול ידני |

## פתרון מוצע

פורטל או טופס דיווח יומי שמחובר ישירות לרשומת המפה:

- שותף המיפוי רואה רק את המפות ששובצו אליו.
- לכל מפה יש דיווח מובנה: הושלם, בוטל, לא הושלם.
- במקרה חריגה חובה להזין סיבה.
- Agent בודק אם הדיווח חסר או סותר.

## מידע נכנס

| מקור | מידע |
|---:|---:|
| OPS | משמרת ומפות משובצות |
| שותף מיפוי | סטטוס ביצוע, הערות, סיבת חריגה |
| מערכת | סטטוס קודם, תאריך יעד, אחראי |

## פעולה

שותף המיפוי שולח דיווח מובנה. המערכת מעדכנת את סטטוס המפה, מוסיפה אירוע לוג, ומעבירה מפות שהושלמו לשלב הבא או מפות חריגות לתור טיפול.

## מידע יוצא

| פלט | שימוש |
|---:|---:|
| סטטוס ביצוע | קובע את המשך הזרימה |
| סיבת חריגה | מאפשר טיפול בביטול או אי-השלמה |
| קבצים / הערות | עוברים לגרפיקה, QA או OPS לפי הצורך |
| אירוע דיווח | מאפשר Audit וסיכום משמרת |

## פעולות Agent בטוחות

- לבדוק אם חסר דיווח למפה מתוכננת.
- לסמן דיווח חסר או סותר.
- לבקש השלמה פנימית לפני סגירת הדיווח.
- להעביר מפה שבוטלה לתור חריגים.
- להכין סיכום יומי לפי דיווחי השותף.
- להציג מפות שבוצעו ולא עודכנו בזמן.

## פעולות שדורשות אישור אנושי

- סגירת מפה כהושלמה סופית.
- שינוי דיווח של שותף.
- שליחת הודעה חיצונית לשותף.
- תיאום מחדש בפועל.
- החלפת שותף מיפוי.

## שאלות פתוחות

- איך שותפי המיפוי מדווחים היום בפועל?
- האם יש כמה סוגי שותפים עם פורמטים שונים?
- אילו שדות חובה בדיווח יומי?
- האם אחרי ביצוע המפה חוזרת לגרפיקה, עוברת QA, או נסגרת ישירות?
- מי מאשר דיווח חריג?
