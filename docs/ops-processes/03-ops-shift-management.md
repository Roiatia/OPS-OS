# 03 - ניהול משמרות ב-OPS

## מטרת התהליך

לבנות משמרות ושיבוצים מתוך שני מקורות אמת: מפות שמוכנות לעבודה וזמינות עובדים שהתקבלה מ-Mapping Partner.

## מה ידוע לנו

- ניהול המשמרות ב-OPS נובע מהכנת המפות ומהזמינות של עובדי השותף.
- המצגת מציינת את OPS ואת Supervisor Schedule כחלק מרכזי בזרימה.
- כיום תהליך התזמון לא נוח ומנותק מהמעקב התפעולי.
- ביטולים או מפות שלא הושלמו דורשים תיאום מחדש ידני.

## הבעיה

אם OPS בונה משמרות בלי לראות במקום אחד גם את המפות המוכנות וגם את זמינות העובדים, נוצרים שיבוצים לא יציבים. OPS צריך לבדוק כמה מקורות, להבין מה מוכן, מי פנוי, ומה יכול באמת להיכנס למשמרת.

## איך פותרים את זה היום

| שלב היום | פעולה |
|---:|---:|
| בדיקת מפות מוכנות | OPS בודק מול גרפיקה או קבצים |
| בדיקת זמינות | OPS מקבל זמינות מה-Mapping Partner |
| בניית משמרת | OPS מחבר ידנית בין מפות, עובדים ומפקחים |
| עדכון סטטוס | צריך לעדכן בכמה מקומות |
| שינוי או ביטול | דורש מעקב ותיאום מחדש ידני |

## פתרון מוצע

תור OPS שמציג רק מפות מוכנות לשיבוץ ואת זמינות העובדים הרלוונטית:

- מפה נכנסת לשיבוץ רק אחרי הכנת גרפיקה.
- זמינות Mapping Partner מוצגת ליד המפות.
- Agent שיבוץ מציע משמרת לפי מוכנות, זמינות, עומס ועדיפות.
- אדם מאשר את השיבוץ בפועל.

## מידע נכנס

| מקור | מידע |
|---:|---:|
| גרפיקה | מפות מוכנות לעבודה |
| Mapping Partner | זמינות עובדים וקיבולת |
| OPS | עדיפות, מגבלות, הערות תפעוליות |
| מערכת | סטטוס מפה, תאריך יעד, חריגים |

## פעולה

OPS בונה או מאשר משמרת. המערכת משייכת מפות, עובדים ומפקח, מוסיפה אירוע לוג, ומעבירה את המפות לביצוע.

## מידע יוצא

| פלט | שימוש |
|---:|---:|
| משמרת מתוכננת | בסיס לביצוע מיפוי |
| מפות משובצות | ברור מה כל משמרת אמורה לבצע |
| עובדים / שותף משויכים | ברור מי מבצע |
| מפקח אחראי | ברור מי מנהל את המשמרת |
| אירוע שיבוץ | מאפשר Audit ומעקב |

## פעולות Agent בטוחות

- להציג מפות מוכנות שלא שובצו.
- להציג זמינות עובדים שלא נוצלה.
- לזהות חוסר התאמה בין כמות מפות לזמינות.
- להציע טיוטת משמרת.
- להתריע על עומס חריג או SLA בסיכון.
- לתעד המלצה בלוג.

## פעולות שדורשות אישור אנושי

- יצירת משמרת בפועל.
- שינוי שיבוץ.
- החלפת מפקח או עובד.
- שינוי תאריך יעד.
- שינוי עדיפות.
- ביטול משימה.

## שאלות פתוחות

- האם OPS משבץ עובדים ספציפיים או רק קיבולת של השותף?
- איפה מנוהלת היום זמינות העובדים?
- מי מאשר שיבוץ סופי?
- האם יש חוקים קבועים לבניית משמרת?
- האם יש SLA שונה לפי לקוח או סוג מפה?
