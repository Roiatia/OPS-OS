# 05 - טיפול בחריגים ותיאום מחדש

## מטרת התהליך

לוודא שמפות שבוטלו, לא הושלמו, או חסרות מידע לא נעלמות מהמעקב, אלא נכנסות לתור טיפול ברור.

## מה ידוע לנו

- ביטולים ומפות שלא הושלמו הם כאב מרכזי.
- כיום המעקב אחריהם ידני.
- המצגת מתארת Map Cancelled / Uncompleted כחלק מהזרימה.
- תיאום מחדש צריך לחזור לשלב שבו יש מפה מוכנה וזמינות עובדים.

## הבעיה

כאשר מפה מתבטלת או לא מושלמת, היא יכולה להישאר בצ'אט, ביומן, בדוח סוף משמרת או בקובץ צדדי. אם אף אחד לא פותח טיפול ידני, המפה עלולה להישכח.

## איך פותרים את זה היום

| שלב היום | פעולה |
|---:|---:|
| זיהוי חריגה | OPS או שותף מזהים ביטול / אי-השלמה |
| תיעוד | הסיבה נרשמת ידנית אם זוכרים |
| מעקב | OPS עוקב דרך הודעות, Excel או יומן |
| תיאום מחדש | נפתח ידנית לפי זמינות |
| חזרה לזרימה | המפה חוזרת להכנה, זמינות או שיבוץ לפי הצורך |

## פתרון מוצע

כל חריגה יוצרת אוטומטית משימת טיפול:

- מפה שבוטלה עוברת לתור חריגים.
- מפה שלא הושלמה דורשת סיבה.
- Agent טיפול בחריגים בודק האם צריך הכנת גרפיקה מחדש, זמינות חדשה או רק שיבוץ מחדש.
- OPS מאשר את הפעולה בפועל.

## מידע נכנס

| מקור | מידע |
|---:|---:|
| שותף מיפוי | ביטול, אי-השלמה, סיבה |
| OPS | החלטת טיפול ותעדוף |
| מערכת | סטטוס קודם, אחראי, תאריך יעד |
| גרפיקה / שותף | האם נדרשת הכנה או זמינות חדשה |

## פעולה

המערכת פותחת משימת טיפול לכל חריגה, מצמידה לה סיבה ואחראי, ומחזירה אותה לשלב המתאים: הכנת גרפיקה, איסוף זמינות, שיבוץ OPS או סגירה.

## מידע יוצא

| פלט | שימוש |
|---:|---:|
| משימת חריגה | מאפשרת מעקב במקום הודעות מפוזרות |
| סיבת ביטול / אי-השלמה | מאפשרת ניתוח ושיפור |
| הצעת חזרה לזרימה | מקצרת עבודה ידנית |
| אירוע לוג | מתעד את כל ההחלטות |

## פעולות Agent בטוחות

- לזהות מפה שבוטלה או לא הושלמה.
- לפתוח משימת חריגה.
- לבדוק אם חסרה סיבת חריגה.
- לסמן מפה כ"דורשת טיפול".
- להציע לאיזה שלב להחזיר את המפה.
- להציג חריגים לפי דחיפות או גיל.

## פעולות שדורשות אישור אנושי

- תיאום מחדש בפועל.
- שינוי שיבוץ.
- ביטול סופי של מפה.
- שינוי עדיפות.
- סגירת חריגה ללא טיפול.

## שאלות פתוחות

- מהן סיבות הביטול הנפוצות?
- מי אחראי לסגור חריגה?
- האם כל ביטול חוזר אוטומטית לשיבוץ או שיש ביטולים סופיים?
- האם חריגה חוזרת לגרפיקה, לזמינות שותף או ישירות ל-OPS?
- האם יש SLA לטיפול בחריגה?
